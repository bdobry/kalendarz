# Inter — social image rendering

Unmodified static Inter Regular and Bold TTF files from the official [Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1), distributed under the included SIL Open Font License (`OFL.txt`).

These fonts are used only by the build-time SVG renderer. Bundling them makes the PNG output independent of installed system fonts and network access; it does not add fonts to the browser JavaScript bundle.
